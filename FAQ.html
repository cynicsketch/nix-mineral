Why won't my system boot?

Try setting nix-mineral.settings.kernel.busmaster-bit = false; since it may cause boot failure on some hardware.

If you are getting errors about failed mounts, review nix-mineral.filesystems.normal and make sure any directory that is dedicated a specific partition of subvolume is not bind mounted.

You can see all the mountpoints that are hardened by default here: https://github.com/cynicsketch/nix-mineral/blob/main/filesystems/normal.nix
